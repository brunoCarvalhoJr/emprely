# AGENTS.md - Landing

## Fluxo obrigatório

Antes de alterar landing:

1. Confirmar se a alteração será na landing existente ou neste monorepo.
2. Criar análise em `apps/landing/.cursor/analise/`.
3. Criar spec em `apps/landing/spec/`.
4. Validar SEO, build estático e impacto na Landing V2.

## Convenções

- Landing V1 atual é externa ao monorepo.
- Landing V2 deve usar prints reais do produto.
- Não criar checkout/eventos finais antes do MVP demonstrável.
