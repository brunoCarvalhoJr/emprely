# AGENTS.md - Web

## Fluxo obrigatório

Antes de alterar o web:

1. Criar análise em `apps/web/.cursor/analise/`.
2. Criar spec em `apps/web/spec/`.
3. Validar rotas, componentes, forms, estados e chamadas de API.
4. Implementar conforme a spec.

## Convenções

- Usar React com Vite.
- Interface deve ser uma ferramenta real, não uma landing.
- Preferir componentes simples e reutilizáveis.
- Usar PortuguesIngles em funções, arquivos e variáveis de domínio.
- Usar lucide-react para ícones quando houver ícone aplicável.
