# Spec Web - Preview mobile com zoom

## Componentes

- `proposal-view-modal-dialog`
- `template-preview-dialog`
- `PreviewPropostaVisual`

## Estados

- Inteiro: documento inteiro visivel.
- Zoom: documento maior para leitura.
- 100%: documento em escala real com scroll.

## Criterios de aceite

- Preview de template nao corta lateralmente no modo inicial.
- Preview da proposta em construcao nao corta lateralmente no modo inicial.
- Controles de zoom e fechar ficam acessiveis no topo.
