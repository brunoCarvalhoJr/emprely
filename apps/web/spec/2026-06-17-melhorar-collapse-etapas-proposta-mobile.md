# Spec Web - Collapse de etapas da proposta mobile

## Componentes

- `PropostaWizardBar`
- `.proposal-wizard-mobile-list`

## Estados

- Concluido: check e texto `Concluido`.
- Atual: destaque e texto `Atual`.
- Pendente: numero e texto `Pendente`.

## Criterios de aceite

- Lista expandida nao quebra texto.
- Layout cabe em 390px.
- Usuario entende rapidamente onde esta no fluxo.
