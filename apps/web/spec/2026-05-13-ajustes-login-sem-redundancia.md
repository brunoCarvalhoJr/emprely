# Spec Web - Ajustes Login Sem Redundancia

## User Story

Como usuario, quero uma tela de login limpa e direta, com a marca Emprely bem aplicada e sem informacoes repetidas, para acessar o sistema rapidamente.

## Requisitos Tecnicos

- `AuthContent` continua recebendo as mesmas props.
- Campos de cadastro/login continuam usando `CampoTexto`.
- `SubmitButton` continua sendo usado.
- Nenhum contrato de API muda.
- Footer nao deve provocar scroll na pagina publica.

## Requisitos Visuais

- Favicon/simbolo Emprely em destaque.
- Uma unica assinatura visual de marca.
- Sem preview de proposta.
- Copy curta e objetiva.
- Sem scroll global da pagina.
- Painel de formulario com scroll interno se necessario.
