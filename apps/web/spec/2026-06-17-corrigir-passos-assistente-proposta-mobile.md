# Spec Web - Corrigir passos do assistente de proposta no mobile

## Visao geral

O assistente inicial da nova proposta deve apresentar os passos de forma compacta e legivel no mobile.

## Componentes

- `proposal-assistant-steps`: novo estilo visual do assistente.
- `proposal-wizard-steps`: permanece para outros contextos.

## Criterios de aceite

- Passos nao quebram visualmente.
- Layout cabe em 390px.
- Tela nao gera scroll horizontal.
- Deploy web continua renderizando sem tela branca.
