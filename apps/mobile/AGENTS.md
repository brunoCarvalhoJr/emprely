# AGENTS.md - Mobile

## Fluxo obrigatório

Antes de alterar o mobile:

1. Criar análise em `apps/mobile/.cursor/analise/`.
2. Criar spec em `apps/mobile/spec/`.
3. Validar navegação, telas, API e limitações nativas.

## Convenções

- Expo entra somente quando a fase mobile for iniciada.
- Mobile deve reaproveitar API, tokens e tipos.
- Priorizar consulta/envio de propostas e uso pelo celular.
- Usar PortuguesIngles em funções, arquivos e variáveis de domínio.
