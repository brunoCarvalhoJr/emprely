# Spec - Hero e CTAs do dashboard

## Escopo

Atualizar o hero do dashboard do app web.

## Requisitos

- Trocar o texto "Emprely Orcamentos" do selo por "Crie orcamentos profissionais em minutos".
- Aumentar a fonte do selo para que ele assuma o papel de chamada principal.
- Remover o titulo duplicado abaixo do selo.
- Exibir tres botoes no hero:
  - Cadastrar proposta
  - Cadastrar servico
  - Cadastrar cliente

## Criterios de aceite

- O dashboard nao deve mostrar duas vezes "Crie orcamentos profissionais em minutos".
- O botao de cliente deve abrir o fluxo de cadastro de cliente.
- Os botoes devem continuar responsivos no desktop e no mobile.
