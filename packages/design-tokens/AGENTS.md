# AGENTS.md - Design Tokens

## Fluxo obrigatório

1. Criar análise em `packages/design-tokens/.cursor/analise/`.
2. Criar spec em `packages/design-tokens/spec/`.
3. Validar impacto visual em web, mobile e landing.

## Convenções

- Tokens devem ser semânticos.
- Evitar temas de uma cor só.
- Usar nomes PortuguesIngles quando o token representar domínio do produto.
